# Trimurti AgroTech

> A modern and professional web platform for Trimurti AgroTech, showcasing tractor components, agricultural products, manufacturing capabilities, and company information.

## 🌐 Live Website

**[Visit Trimurti AgroTech →](https://trimurti-agro-tech.vercel.app/)**

## 📌 About the Project

Trimurti AgroTech is a responsive corporate website designed to establish a strong digital presence for an agricultural and tractor components manufacturing business.

The website provides information about the company, its products, manufacturing capabilities, gallery, and contact/enquiry options through a clean and user-friendly interface.

## ✨ Features

- Modern and responsive UI
- Professional corporate design
- Product and tractor component showcase
- Manufacturing information
- Company gallery
- Contact and enquiry sections
- Mobile-friendly design
- Smooth navigation and animations
- SEO-friendly structure

## 🛠️ Tech Stack

- React.js
- TypeScript
- Vite
- Tailwind CSS
- JavaScript
- HTML5
- CSS3

## 📂 Main Sections

- Home
- About Us
- Products
- Manufacturing
- Gallery
- Contact

## 🎯 Purpose

The project is designed to provide Trimurti AgroTech with a professional online presence and make its products and manufacturing capabilities easily accessible to customers and business partners.
